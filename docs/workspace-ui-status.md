# Workspace UI Status

Next.js 側ワークスペースUIの現状メモです。  
設計方針ではなく、「いま何が入っているか」「次に何を見るべきか」を残します。

## 現在の到達点

ワークスペースUIは、`古物台帳`, `仕入れ管理`, `EC販売` を同じ操作感で扱える段階まで整理できています。

入っている内容:

- サイドバー中心のメニュー構成
- ヘッダーはブランド表示と現在地表示に簡素化
- 各画面の見出し帯、余白、文字サイズを圧縮して密度を統一
- 主要ボタンの見た目を共通化
- 古物台帳を `受入れ / 払出し / 相手方・確認` のタブ構成に変更
- 古物台帳にステータスフィルター、検索、件数表示を追加
- 古物台帳 / 仕入れ管理 / EC販売に共通ページネーションを追加
  - 1ページ20件固定
- 横長テーブルに共通ドラッグスクロールを追加
  - `grab / grabbing` カーソル
- `768px以下` で試験的な狭幅レイアウトへ切り替え
  - サイドバーをドロワー化
  - ヘッダーにメニューボタン追加
  - オーバーレイクリックで閉じる

## レスポンシブ方針

現時点では、モバイル最適化を完成させることは目的にしていません。  
方針は `スマホ専用UIを作る` ではなく、`狭い画面でも破綻しにくくする` です。

現在の扱い:

- `769px以上`
  - デスクトップ前提レイアウト
  - サイドバー常設
- `768px以下`
  - 試験的なドロワーレイアウト
  - サイドバーはヘッダーボタンから開閉
  - 見出し、フィルター、モーダルは縦積み寄りに変更
  - テーブル自体はカード化せず横スクロール前提

このため、スマホ運用を保証する状態ではなく、`タブレット〜狭いノートPCでも破綻しにくい基盤` を作っている段階です。
